# Order Summary — React + Vite

Responsive React implementation of the Crio order summary component.

## Requirements
- Node.js 18+ recommended
- npm

## Install and run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Assessment checklist
- Required classes are present: `.main`, `.container`, `.heading`, `.summary-para`, `.plan-text`, `.change-link`, `.proceed-btn`, `.cancel-order`.
- Exact required copy is included.
- Proceed button background changes on hover.
- Cancel Order link color changes on hover.
- Responsive layout and distinct body background treatment at the `450px` mobile breakpoint.

Before submitting, deploy the app and put only the deployed URL in `submit.txt` in your project root. Copy the project into the Crio workspace if you need to run Crio's assessment script.
